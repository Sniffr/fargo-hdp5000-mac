# HID Fargo HDP5000 — reverse-engineering notes

Goal: a native Apple-silicon CUPS driver for the HDP5000, rebuilt from HID's
2012 Mac driver (`HDP5000_MAC_ V1.0.0.4.pkg`, OS X 10.4/10.5, i386 only).

## Layout

| Path | What |
|---|---|
| `original/payload/` | Unpacked HID package (filter, PPD, ICC profiles, sample .prn jobs) |
| `emu/run_original.py` | Runs HID's i386 filter under Unicorn → byte-exact reference output |
| `emu/macho.py` | Minimal i386 Mach-O loader (segments, symbols, import stubs) |
| `emu/coverage.py`, `emu/trace_compress.py` | Instrumentation helpers |
| `tools/prnparse.py` | Splits a .prn job into packets |
| `tools/render_prn.py` | Renders each panel of a job to PNG |
| `analysis/filter_annot.asm` | Full disassembly with import names resolved |
| `reference/` | Reference outputs generated by the original filter |

The original filter is **not stripped** (3,955 symbols): it is HID's Windows
"FargoRip" engine ported to CUPS through a GDI shim, plus SampleICC for colour.

## Wire format (what goes to the printer)

Packets: `'F' <type> <u16le version=1> <u16le len> <payload> 'e' 'P'`

* `Fs` len 0, then `Fs` len 8 (zeros) — start of job
* `Fg` — command stream, chopped into ≤512-byte payloads
* raw `ESC 00 02 <c>` — maintenance commands: `c` clean, `f` film cal,
  `l` laminator cal, `r` ribbon cal

Command stream inside the joined `Fg` payloads: records `u32le op, u32le len, body[len]`

| op | meaning (so far) |
|---|---|
| 0x01 | job info (len 34 in 2009 jobs, 40 from the 2012 filter) |
| 0x03 | settings (len 10) |
| 0x0f | panel header (len 22): `u16 0x10, u16 panel_idx, u16 1, u16 panel_code, u32 0, u16 lines, u32 size, …` |
| 0x10 | scan line: `u32 0x10, u32 0, u16 repeat, [2 bytes in 2012 format], RLE data` |
| 0x11, 0x12 | trailer settings (0x12 carries 0x12c = 300) |
| 0x63 | end of job |

Scan lines are 768 dots (head width), 1 byte per dot = burn level (0 = no
ink). RLE (decoded from `_ripCompressPLineHorz`): control `c < 0x80` → repeat
next byte `c+1` times; `c ≥ 0x80` → copy `c-0x7f` literal bytes. Identical
consecutive lines are merged by bumping the repeat count.

Panels: YMC (+K resin) sent in order; panel codes 1,2,3,4. CR80 page from
CUPS is 662×1033 RGB @300dpi, placed inside the 768-dot head width.

## Colour pipeline (default)

1. CUPS raster: 8-bit RGB chunky, 300 dpi.
2. SampleICC: `sRGB.icm` → `HDP5000CLR.icm` (RGB→Lab PCS→device RGB), per pixel.
   `ColorMatching=None` disables it (black threshold then 0x020202 instead of 0x001019).
3. FargoRip per line: defined print area, K-panel extraction, `ripDyeSub3Color1Resin`
   (YMC + resin K), sharpening, FA colour transform (gamma/lumin), thermal
   head model, ribbon-wrinkle compensation, compression, spooling, packets.

### Thermal head model (decompiled)

```
nCalculateResidualEnergy(a0..a10):
  k = (2*a3 > a0+a1) ? a7 : a10
  r = ((a0-a3)+(a1-a3))*k + ((a2-a3)+(a4-a3))*a8 + ((a5-a3)+(a6-a3))*a9
  return min(0xffff, (r+3000)/6000 + a3)          // C int division

nUpdateEnergy(cell, st[4], level, eA, eB):        // cell = int*, row stride 0xc38 bytes
  nxt = cell + 0xc38/4
  cur = ((level*5120 + 204800)/22 + (cell[2] & 0xffff)) / 2
  st[1] = R(100,100, eA,eB, cur, nxt[0],nxt[1], 100,1000,170,100)
  st[3] = R(eA,eB, nxt[0],nxt[1],nxt[2], nxt[0]/30, nxt[2]/30, 50,1000,1,50)
  cell[0]=st[0]; nxt[0]=st[2]; st[0]=st[1]; st[2]=st[3]
  return cur

uAdjustBurnLevel(level, cell):
  nxt = cell + 0xc38/4 ; c = cell[2]
  S = 170*((nxt[2]-c)+(nxt[3]-c)) + 1000*(cell[1]-c) + 1000*(cell[3]-c)
  e = 380*level - (S/4096 + c)
  return clamp((22*e + 459800)/5120 - 40, 0, 255)
```

## Outcome: static recompilation (instead of hand-porting)

Hand-decompiling the ~36k-instruction FargoRip pipeline plus SampleICC was
replaced by a mechanical recompiler (`lifter/lift.py`): capstone decodes each
of the 2,465 functions (recursive descent, PIC switch tables resolved from
`cmp N / ja / lea OFF(%ebx)`), and every instruction becomes C operating on
a flat 32-bit guest address space. Guest calls map to C calls; the guest stack
stays in guest memory. `lifter/rt.c` re-implements the 104 imports (libc,
libcups raster/options/PPD defaults, the gcc-4.0 COW std::string, list and
red-black tree helpers). Old `/usr/share/...` data paths are remapped to
`/Library/Printers/Fargo/HDP5000/` (override with `HDP5000_DATADIR`).

Verification: 59 jobs byte-identical to the emulated original (option sweeps on
blank and colour pages, stress images, duplex, mag encoding, lamination).
Native speed: 0.5–1.4 s per card versus 6–30 s emulated.

HID PPD fixes needed for modern CUPS (output unchanged, verified): `**CloseUI`
typo, `OpenUI` lines without `: PickOne`, lamination defaults `None` → `0`
(same output), duplicate `LaminationPosition` choices.

Package: `driver/Fargo-HDP5000-2.0.0.pkg` (pkgbuild from `driver/pkgroot`,
postinstall sets root:wheel and go-w so cupsd accepts the filter).

Still unverified until a printer is attached: the USB device ID and URI, and
whether the 2012-format 12-byte line header suits this unit's firmware. HID's
Mac driver sent that format, so it is expected to work.
